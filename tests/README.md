# Проверки ШТАБа

14 наборов проверок: приложение в Chromium (Playwright) и Worker на локальной базе D1 (wrangler).
Данные вымышленные: `make-fixtures.mjs` при каждом запуске строит базу той же формы и объёма,
что настоящая (64 ученика, 884 занятия, большая заметка, тренажёры), и школьный слой на 914 записей.
Настоящих имён, расписаний и выгрузок здесь нет и быть не должно.

## Как запустить

Нужны Node 20+, Python 3 и npm. Из корня репозитория:

```
bash tests/run.sh
```

Первый раз поставятся Playwright и wrangler (папка `tests/node_modules`). Если Chromium для
Playwright ещё не скачан: `cd tests && npx playwright install chromium`.

Скрипт сам поднимает приложение на `127.0.0.1:8000` и Worker на `127.0.0.1:8787` (у каждого запуска
своя пустая база), гоняет все наборы и в конце пишет «ВСЕ ПРОВЕРКИ ПРОШЛИ» или список провалившихся.
Порты 8000 и 8787 должны быть свободны.

В GitHub: вкладка Actions → «Проверки ШТАБа» → Run workflow.

## Что проверяется

Worker (`server-*.mjs`):
- `server-sync` – запись и чтение по записям, правило «новее побеждает», удаления, большие пакеты, ICS;
- `server-ics` – календарь-подписка в UTC: занятия по МСК, школьные уроки по Бишкеку, каникулы;
- `server-snapshots` – снимки облака: снимок дня, версии без дублей, выгрузка, откат со словом ВЕРНУТЬ,
  отмена отката, срок хранения 60 дней.

Приложение (остальные `*.js`, по одному файлу на набор):
- `tz_view` – показ по времени Бишкека с МСК в скобках, перенос, слой «Школа», «Добавить из файла»;
- `e2e` – синхронизация двух устройств: слияние, правки, удаления, конфликт, работа без сети;
- `link` – подключение по ссылке;
- `fresh_join` – новое устройство не портит облако;
- `sync_school` – школьный слой и отметки расходятся по устройствам;
- `import_safety` – «Заменить базу» только со словом ЗАМЕНИТЬ;
- `student_actions` – оплачено до даты, новая цена, отпуск, ученик ушёл;
- `schedule_tools` – накладки, шаблон из расписания, «Продлить на месяц», объединение, архив вместо удаления;
- `snap_ui` – панель «Снимки облака»: скачивание, откат и его отмена;
- `tz_autoclose` – устройство в Бишкеке не закрывает занятие, которое по Москве ещё впереди.
- `merge_names` – «Добавить из файла» привязывает тренажёры из воскресной дельты к ученику по имени.

## Время в тестах

Браузерные тесты начинаются 29.10.2026 в 12:00 по Москве, дальше время идёт обычно (`clock.cjs`).
Поэтому проверки с ноябрьскими датами не устаревают. Другую точку старта можно задать
переменной `SHTAB_TEST_NOW`, например `SHTAB_TEST_NOW=2026-12-01T09:00:00Z bash tests/run.sh`.
