## 2. Как обновить сайт

1. Открой https://github.com/canulovesmtorsmb/shtab
2. `Add file` → `Upload files`
3. Перетащи все пять файлов из папки `сайт/`
4. Внизу нажми `Commit changes`
5. Подожди минуту, обновится по адресу https://canulovesmtorsmb.github.io/shtab/

**На телефоне после обновления:** закрой приложение полностью (смахни из списка запущенных) и открой заново. Service worker подтянет новую версию. Если версия всё равно старая — открой сайт в обычном браузере, обнови страницу, потом снова запусти с иконки.

---

## 3. Как обновить Worker

1. Cloudflare → Workers & Pages → `shtab-sync`
2. `Edit code`
3. Выдели весь текст в редакторе, удали, вставь содержимое `cloudflare/worker.js`
4. `Deploy`

Проверить, что живой: открой https://shtab-sync.siroqmanpilot.workers.dev/health — должно ответить `{"ok":true,"service":"shtab-sync"}`

## 4. Что нового в этой сборке

### Ссылки Zoom к занятиям

**Где настроить:** Календарь → кнопка `Ссылка Zoom`

Вставь туда ссылку на свою личную конференцию. Взять её так: Zoom → Конференции → вкладка Личная конференция → Копировать приглашение. Ссылка вида `https://us05web.zoom.us/j/8412345678`. Код доступа — отдельным полем, если он у тебя включён.

Дальше эта ссылка сама подставляется во все занятия. Пользоваться можно из трёх мест:

- **Правая кнопка на карточке занятия** → «Zoom: подключиться», «копировать ссылку», «копировать приглашение», «своя ссылка…»
- **Внутри запущенного урока** — кнопки `Zoom` и `Приглашение` в шапке
- **В напоминании за 30 / 10 / 5 минут** — кнопка «Подключиться» рядом с «Запустить урок»

**Если для конкретного занятия нужна другая ссылка:** впиши её в поле «Ссылка Zoom для этого занятия» в карточке занятия либо через правую кнопку → «Zoom: своя ссылка…». Она перебьёт постоянную только для этого урока. Чтобы вернуть постоянную — очисти поле.

**Шаблон приглашения** настраивается там же. Если оставить пустым, ШТАБ соберёт текст сам:

```
Настя, занятие 12 августа в 14:00.
Русский язык · Причастный оборот
Подключиться: https://us05web.zoom.us/j/8412345678
Код доступа: 4821
```

Даты подставляются по-человечески: «сегодня», «завтра», «12 августа». Свои подстановки для шаблона: `{ученик}` `{когда}` `{дата}` `{время}` `{предмет}` `{тема}` `{ссылка}` `{код}` `{длительность}`. Прямо в окне настройки видно, как текст будет выглядеть у ученика.

### Синхронизация теперь честно говорит, что сломалось

Раньше при отказе сервера ШТАБ молча ничего не делал и показывал «последняя синхронизация: только что». Теперь ошибка выводится текстом и красным.

**Новая кнопка `Проверить связь`** в разделе Синхронизация. Она проверяет по шагам: заполнен ли ключ, жив ли Worker, отдаёт ли он данные, и сравнивает количество записей на сервере с тем, что лежит на этом устройстве. Отчёт можно скопировать одной кнопкой.

### Учебник

Большие тексты из классики теперь в 21 теме, всего 43 отрывка по 190–260 слов. Пунктуационные темы получили пропуски нового типа: ученик решает не только какой знак нужен, но и нужен ли он вообще.

## 5. Если синхронизация не работает на телефоне

Открой на телефоне Синхронизация → `Проверить связь` и посмотри первые строки отчёта.

**«Ключ пространства: НЕ ЗАДАН»** — самая частая причина. Телефон потерял ключ. Safari удаляет данные сайта, если не заходить в него неделю-другую. Возьми ключ с компьютера (Синхронизация → Копировать ключ) и вставь на телефоне.

**«Worker отклонил доступ: не совпадает токен»** — в Cloudflare задан секрет `APP_TOKEN`, а на телефоне он не вписан. Либо впиши тот же токен в Синхронизация → Дополнительно → Токен, либо убери секрет в Cloudflare: Settings → Variables and Secrets → удалить `APP_TOKEN`.

**«Worker недоступен»** — либо нет интернета, либо в поле «Адрес Worker» опечатка. Правильный адрес: `https://shtab-sync.siroqmanpilot.workers.dev`

**Данные расходятся по количеству** — реши, какое устройство считать главным. На главном нажми «Отправить на сервер», на втором — «Загрузить с сервера». Перед этим на всякий случай сделай выгрузку базы: кнопка экспорта в шапке.
